# Captured programmes

Empty on purpose. Modules here are generated from a private vault and are not
committed: they contain real source prose, and a record marked shareable can
still discuss sequences, vendors and prices in its own body.

`active.ts` decides which cut a build compiles. Shipped as `none`, so this
repository carries no captured programme and the PeptAI workspace is empty.
The VivaMed workspace is synthetic fixtures and works without any of this.

To capture a programme locally, see [`../../../VAULT-INTAKE.md`](../../../VAULT-INTAKE.md).
